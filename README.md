# HildaSoftLight

Исследовательский проект мода для **Asterigos: Curse of the Stars**: очень слабый локальный свет, который помогает видеть Хильду в тенях и немного освещает ближайшие поверхности, сохраняя темноту локаций.

Готового мода и файла для установки пока нет. Штатный Glimmer должен сохранить своё поведение; глобальная экспозиция, гамма и тонмаппинг не меняются.

Первый статический этап завершён: [отчёт в research/lighting-feasibility](https://github.com/NikichMods/HildaSoftLight/blob/research/lighting-feasibility/docs/LIGHTING_FEASIBILITY.md). Предпочтительный кандидат — собственный PointLightComponent без теней на персонаже. Его работу в игре и визуальные параметры ещё предстоит проверить.
