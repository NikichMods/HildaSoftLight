# Статус

Создана самостоятельная документальная основа проекта. Готового мода, runtime-пробы, установленного payload и версии нет.

Следующий шаг — ограниченное статическое исследование в `research/lighting-feasibility`: установить штатную световую цепочку, сравнить независимый Actor и компонент, проверить отражённые методы и назвать минимальную оставшуюся runtime-неопределённость. Доступ к игре только на чтение, запуск/установка не разрешены этим этапом.
