# Статус

Первый ограниченный этап **завершён: bootstrap + статическая feasibility**, 2026-10-30. [Результаты и доказательства](LIGHTING_FEASIBILITY.md), [хэши входов](STATIC_EVIDENCE.json). Начальная основа main опубликована отдельно; исследовательские записи принадлежат `research/lighting-feasibility`.

Предпочтительный кандидат для проверки — отдельный transient Engine.PointLightComponent с pawn Outer и attachment к root вне штатной ветки `light`; он использует общий маршрут R-016. Это не утверждённая production-архитектура и не runtime PASS света.

Найдены штатный шаблон PointLight Хильды, его SCS-ветка и Blueprint-контроль через `flash_light`/Lights. Подтверждены декларации методов в сохранённом UHT и SpawnActor binding UE4SS83330635. Создание/рендер/следование/очистка именно PointLightComponent и полный level/pawn lifecycle остаются непроверенными.

**Production gate BLOCKED.** Готового мода, версии, релиза, runtime-пробы и установленного payload нет. Визуальные числа не выбраны.

Следующий необходимый шаг — после отдельного задания подготовить один ограниченный runtime-эксперимент: собственный невидимый компонент → регистрация/привязка → краткое on/off в одной сцене при движении Хильды → ручная/timeout очистка. Логи подтверждают object lifecycle; пользователь — реальный свет/исчезновение. Смена уровня и тонкая визуальная настройка не считаются пройденными этим тестом.
